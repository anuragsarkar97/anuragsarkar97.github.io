# Plain blog design

Purpose: find an article, read it comfortably, and continue to another article.
The author's requested direction is super simple: no conspicuous design system,
marketing introduction, ornate publication styling, cards, gradients or hero.

Keep the static Jekyll stack and all article source, published URLs, media,
feed, About, Papershelf and drawing tool. Make the homepage a straightforward
list of article titles and dates, with the author's name as its only H1.
Use Georgia, underlined links, a 38rem reading measure, normal whitespace,
white and dark neutral palettes. Navigation is visible and short; secondary
links live in the footer. The archive uses the same list include as the home.

Retain semantic headings, metadata and canonical URLs, server-rendered code
highlighting, keyboard focus, responsive media and tables, and system/manual
dark mode. No browser framework, web-font dependency or animation is needed.

Validate production output, route and content preservation, local links,
keyboard behavior, responsive layouts and automated accessibility. See
validation.md for measurements, evidence and explicit verification limits.
