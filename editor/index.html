--- layout: page title: Write a post description: A small Markdown editor for drafting a new blog post. editor: true ---

Write in Markdown and save into _posts/. Choose that folder the first time you save, then publish the site as usual.

Use ## for headings, **bold**, [links](https://example.com), and fenced code blocks with a language name.

Preview

Folder saving is unavailable in this browser. Use Download Markdown, or open this editor in Chrome.

Your draft stays in this browser. Save a file to keep it.
